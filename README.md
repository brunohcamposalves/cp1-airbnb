# CP1 Clone Airbnb

Este projeto é um **clone da página de anúncio do Airbnb**, criado com o propósito exclusivo de **aprimorar habilidades em HTML e CSS**, com especial foco em **Flexbox** e **Grid Layout**.  

---

## 🎯 Objetivo  

O projeto não possui finalidade comercial — foi desenvolvido como um exercício prático para:  

- 🧩 Utilizar **HTML semântico** na estruturação da interface.  
- 🎨 Reproduzir layouts visualmente similares à página real do Airbnb.  
- 📱 Aplicar técnicas de **layout responsivo** usando **Flexbox** e **CSS Grid**.  
- 🏷️ Simular componentes típicos de uma página de anúncio (como galeria de fotos, informações de hospedagem, descrições e botões de reserva).  

---

## 🛠️ Tecnologias Utilizadas  

- ⚡ **HTML5**  
- 🎨 **CSS3**  
  - 📐 Flexbox  
  - 🗂️ Grid Layout
